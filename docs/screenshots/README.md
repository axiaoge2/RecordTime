# Screenshots Directory

This directory contains screenshots for the README and documentation.

## Required Screenshots

- `dashboard.png` - Main dashboard view
- `analytics.png` - Analytics/Reports view
- `time-budget.png` - Time budget management view
- `banner.png` - Project banner (optional, 1280x640 or 800x400)

## Screenshot Guidelines

- Resolution: 1200-1600px width recommended
- Format: PNG preferred
- Show meaningful data (not empty states)
- Use consistent window size across screenshots
