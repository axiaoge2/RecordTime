## 一、核心理念

**从"时间追踪工具"升级为"AI 驱动的认知辅助助手"**

> 不是控制时间、管理时间，而是结合人脑的一般规律，顺应认知特点，提供可操作的建议。

---

## 二、四层架构概览

```
┌─────────────────────────────────────────────────────────────┐
│                    第四层：正向反馈（激励层）                   │
│         确定性奖励 + 非确定性惊喜 → 持续参与动力                 │
├─────────────────────────────────────────────────────────────┤
│                    第三层：AI 建议（输出层）                    │
│      LLM + 知识库 + 个人参数 → 可操作的个性化建议                │
├─────────────────────────────────────────────────────────────┤
│                    第二层：知识库（原则层）                     │
│         认知科学原则（静态） + 个人参数（动态学习）               │
├─────────────────────────────────────────────────────────────┤
│                    第一层：精准跟踪（数据层）                   │
│      窗口监控 + 输入监控 + 媒体检测 → 活动类型判定                │
└─────────────────────────────────────────────────────────────┘
```

## 三、第一层：精准跟踪（已完成）

### 3.1 活动类型检测

| 优先级 | 类型 | 检测逻辑 | 状态 |
|--------|------|----------|------|
| 1 | Idle | 空闲 >5分钟无输入 | ✅ |
| 2 | Video | MediaSession播放 / 视频应用+音频活动 | ✅ |
| 3 | Meeting | 会议应用进程 + 音频活动 | ✅ |
| 4 | Gaming | 全屏+高频输入 / 游戏相关进程名 | ✅ |
| 5 | ActiveTyping | >20键/30秒 或 >10键+>5点击/30秒 | ✅ |
| 6 | Reading | 滚轮>10次/30秒 + 键盘<5次/30秒 | ✅ |
| 7 | PassiveBrowsing | 窗口有焦点但未达到以上阈值 | ✅ |

### 3.2 系统状态采集

| 数据 | 来源 | 用途 |
|------|------|------|
| 键盘活动 | InputMonitor (30s窗口) | 活动类型判定 |
| 鼠标点击 | InputMonitor (30s窗口) | 活动类型判定 |
| 滚轮滚动 | InputMonitor (30s窗口) | 阅读检测 |
| 应用切换 | WindowMonitor (1/5/10min) | 专注度评估 |
| 媒体播放 | MediaDetector | 视频/音乐检测 |
| 后台音乐 | MediaDetector | "边听边做"场景 |
| IsDeepFocus | 5分钟切换<3次 | 心流状态保护 |
| IsAttentionFragmented | 5分钟切换>10次 | 碎片化警告 |

### 3.3 数据存储

- 会话数据: SQLite (`AppSession` 表)
- 心跳机制: 每30秒更新 `LastHeartbeat`
- 隐私保护: 窗口标题 SHA256 哈希

## 四、第二层：知识库（设计中）

### 4.1 认知科学原则（静态）

详见 `docs/COGNITIVE_SCIENCE_KNOWLEDGE_BASE.md`

核心原则：

| 原则 | 核心发现 | 应用场景 |
|------|----------|----------|
| 超日节律 | 90-120分钟认知周期 | 休息提醒时机 |
| 任务切换成本 | 切换后需15-25分钟恢复 | 减少切换建议 |
| 注意力残留 | 未完成任务持续占用资源 | 任务完成建议 |
| 认知负荷 | 工作记忆4-7个块 | 任务分解建议 |
| 自我损耗 | 自控力像肌肉会疲劳 | 决策时机建议 |
| 心流理论 | 技能-挑战平衡 | 保护专注状态 |
| 昼夜节律 | 一天中认知高峰/低谷 | 任务安排建议 |
| 微休息 | 短休息比长休息更有效 | 休息方式建议 |

### 4.2 个人参数（动态学习）

#### 参数列表

| 参数 | 默认值 | 学习方法 | 数据来源 |
|------|--------|----------|----------|
| 专注周期长度 | 90分钟 | 会话时长中位数 | AppSession |
| 高效时段 | 10-12, 16-18 | 时段活跃度统计 | AppSession |
| 切换容忍度 | 10次/5分钟 | 切换频率基线 | SystemState |
| 休息模式 | - | 空闲时段分析 | AppSession |
| 工作模式 | - | 应用组合分析 | AppSession |

#### 学习阶段

```
阶段1: 冷启动（0-7天）
├── 100% 使用知识库默认值
├── 开始收集数据
└── 不做个性化推断

阶段2: 初步学习（7-30天）
├── 计算初步统计
├── 置信度低 → 继续用默认值
└── 置信度高 → 开始个性化

阶段3: 稳定个性化（30天+）
├── 大部分参数使用个人数据
├── 滚动更新（近期权重更高）
└── 检测长期趋势变化
```

#### 置信度计算

```
实际值 = 默认值 × (1 - 置信度) + 个人值 × 置信度

置信度因素：
- 样本数量（数据点越多越可靠）
- 数据一致性（方差小说明模式稳定）
- 时间跨度（覆盖不同日期类型）
```

### 4.3 隐私边界（已确定）

#### 数据发送策略

**选择方案 C：完整信息发送**

| 数据类型 | 是否发送 | 示例 |
|----------|----------|------|
| 统计摘要 | ✅ 发送 | "今日专注4.2小时" |
| 应用分类 | ✅ 发送 | "开发工具3.2小时" |
| 应用名称 | ✅ 发送 | "VS Code 3.2小时" |
| 时间精度 | 精确到分钟 | "14:32开始，已持续67分钟" |
| 窗口标题 | ❌ 不发送 | - |
| 文件名/内容 | ❌ 不发送 | - |

#### 设计理由

1. **用户已信任应用**：用户安装并使用 RecordTime 记录使用时间，已建立信任
2. **精准建议需要精准数据**：模糊信息只能得到模糊建议
3. **固定方案降低复杂度**：不提供隐私级别选项，简化用户决策
4. **底线明确**：永不发送窗口标题、文件名等内容级信息

### 5.3 Prompt 构建架构

所有交互（快捷按钮/自由对话）共享同一套 Prompt 结构：

```
┌─────────────────────────────────────────────────────────────┐
│ [1] 系统角色设定                              ← 固定不变     │
├─────────────────────────────────────────────────────────────┤
│ [2] 知识库原则                          ← 静态，始终注入     │
│     超日节律、任务切换成本、心流理论...                       │
├─────────────────────────────────────────────────────────────┤
│ [3] 个人参数                            ← 动态，从数据学习   │
│     专注周期、高效时段、切换容忍度...                        │
├─────────────────────────────────────────────────────────────┤
│ [4] 当前状态                            ← 实时，每次采集     │
│     今日数据、当前会话、切换频率...                          │
├─────────────────────────────────────────────────────────────┤
│ [5] 用户问题                            ← 预设或用户输入     │
│     快捷按钮：预设 Prompt                                   │
│     自由对话：用户输入                                      │
└─────────────────────────────────────────────────────────────┘
```

**关键点**：快捷按钮本质是预设的高质量 Prompt，与自由对话只是 [5] 部分不同。

### 5.6 建议类型

| 类型 | 触发条件 | 示例 |
|------|----------|------|
| 休息提醒 | 接近专注周期边界 | "你已经专注了85分钟，建议休息5-10分钟" |
| 切换警告 | 注意力碎片化 | "最近5分钟切换了15次，每次切换需要恢复时间" |
| 时段建议 | 高难度任务+非高效时段 | "现在是你的低效时段，建议处理简单任务" |
| 心流保护 | 检测到深度专注 | (不打断，延迟非紧急通知) |
| 休息肯定 | 合理休息后恢复 | "刚才的休息很棒，现在是继续的好时机" |
| 趋势洞察 | 定期报告 | "本周专注时间比上周增加了15%" |
