## 🔴 严重问题 (Critical Issues)

### 1. **内存泄漏 - DbContext 未正确释放**

**文件**: `MainWindowViewModel.cs:180-185`

```csharp
() =>
{
    var dbContext = new RecordTimeDbContext();
    return new SessionRepository(dbContext);
}
```

**问题分析**:
- 每次调用都创建新的 `DbContext` 但从不释放
- `SessionRepository` 不拥有 `DbContext` 的生命周期管理
- 在高频事件(窗口切换)下会快速累积未释放的 DbContext

**影响**:
- 🔥 **严重内存泄漏**
- 数据库连接池耗尽
- 应用长时间运行后性能严重下降

**建议修复**:
```csharp
// 方案1: Repository 实现 IDisposable
public class SessionRepository : ISessionRepository, IDisposable
{
    private readonly RecordTimeDbContext _context;
    private readonly bool _ownsContext;

    public SessionRepository(RecordTimeDbContext context, bool ownsContext = false)
    {
        _context = context;
        _ownsContext = ownsContext;
    }

    public void Dispose()
    {
        if (_ownsContext)
        {
            _context?.Dispose();
        }
    }
}

// 在 SessionManager 中
private async Task StartNewSessionAsync(...)
{
    using var dbContext = new RecordTimeDbContext();
    using var repository = new SessionRepository(dbContext, ownsContext: true);
    // ... 使用 repository
}
```

### 2. **async void 事件处理器导致的异常吞噬**

**文件**: `SessionManager.cs:87`

```csharp
private async void OnWindowFocusChanged(object? sender, WindowInfo window)
{
    // ... 异步操作
}
```

**问题分析**:
- `async void` 会吞噬异常,无法被调用者捕获
- 在事件处理器中抛出的异常会导致应用崩溃
- 无法追踪异常堆栈

**影响**:
- 🔥 **应用意外崩溃**
- 难以调试的运行时错误
- 数据完整性风险

**建议修复**:
```csharp
// 方案: 使用 Task 返回类型,并正确处理异常
private void OnWindowFocusChanged(object? sender, WindowInfo window)
{
    // 不等待,但记录任何异常
    _ = HandleWindowFocusChangedAsync(window);
}

private async Task HandleWindowFocusChangedAsync(WindowInfo window)
{
    try
    {
        await _sessionLock.WaitAsync();
        try
        {
            // ... 业务逻辑
        }
        finally
        {
            _sessionLock.Release();
        }
    }
    catch (Exception ex)
    {
        // 记录到日志系统
        _logger.LogError(ex, "处理窗口焦点变化时发生错误");
        // 可选:通知用户
    }
}
```

### 3. **全局键盘/鼠标钩子的性能和稳定性问题**

**文件**: `InputMonitor.cs:83-105`

**问题分析**:
- 全局钩子在每次输入事件时都会执行回调
- 回调中使用了 LINQ `Count()` 操作,时间复杂度 O(n)
- 在 Hook 回调中持有锁时间过长
- Hook 回调必须尽快返回,否则会影响系统输入响应

**影响**:
- 🔥 **系统输入延迟**
- 降低系统整体性能
- 可能被安全软件拦截

**建议修复**:
```csharp
// 使用更高效的数据结构
private readonly ConcurrentQueue<DateTime> _keyboardEvents = new();
private int _keyboardCount = 0;

private IntPtr KeyboardHookCallback(int nCode, IntPtr wParam, IntPtr lParam)
{
    if (nCode >= 0 && wParam == (IntPtr)WM_KEYDOWN)
    {
        var now = DateTime.Now;
        _keyboardEvents.Enqueue(now);
        Interlocked.Increment(ref _keyboardCount);

        // 使用后台线程清理过期数据
        if (_keyboardCount > 1000) // 阈值触发清理
        {
            _ = Task.Run(() => CleanupOldEvents());
        }
    }

    return CallNextHookEx(_keyboardHookId, nCode, wParam, lParam);
}

public int GetKeyboardActivityCount(int seconds)
{
    var cutoff = DateTime.Now.AddSeconds(-seconds);
    var count = 0;
    foreach (var evt in _keyboardEvents)
    {
        if (evt >= cutoff) count++;
    }
    return count;
}
```

### 4. **Dispose 模式实现不正确**

**文件**: `SessionManager.cs:230-234`

```csharp
public void Dispose()
{
    StopAsync().Wait(); // ❌ 阻塞式等待异步方法
    _sessionLock.Dispose();
}
```

**问题分析**:
- 在 `Dispose` 中调用 `.Wait()` 可能导致死锁
- 没有实现完整的 Dispose 模式(IDisposable pattern)
- 没有防止重复释放的保护

**影响**:
- 🔥 **潜在死锁**
- 资源泄漏
- 应用关闭挂起

**建议修复**:
```csharp
private bool _disposed = false;

public void Dispose()
{
    Dispose(true);
    GC.SuppressFinalize(this);
}

protected virtual void Dispose(bool disposing)
{
    if (_disposed) return;

    if (disposing)
    {
        // 同步清理
        _isRunning = false;

        // 等待当前操作完成
        if (_sessionLock.Wait(TimeSpan.FromSeconds(5)))
        {
            try
            {
                _sessionLock.Release();
            }
            catch { }
        }

        _sessionLock?.Dispose();

        // 停止监控服务(同步版本)
        _windowMonitor?.Stop();
        _inputMonitor?.Stop();
        _mediaDetector?.Stop();
    }

    _disposed = true;
}

// 提供异步清理方法
public async ValueTask DisposeAsync()
{
    if (_disposed) return;

    _isRunning = false;

    await StopAsync();

    _sessionLock?.Dispose();
    _disposed = true;

    GC.SuppressFinalize(this);
}
```

### 10. **MediaDetector 性能问题**

**文件**: `MediaDetector.cs:57-94`

**问题**:
- 每次调用都遍历所有进程
- 没有缓存机制

**建议**:
```csharp
private readonly ConcurrentDictionary<int, (string ProcessName, DateTime LastCheck)> _processCache = new();
private readonly TimeSpan _cacheExpiration = TimeSpan.FromSeconds(5);

public bool IsMediaPlaying()
{
    if (!_isRunning) return false;

    try
    {
        var now = DateTime.Now;
        var processes = Process.GetProcesses();

        foreach (var process in processes)
        {
            try
            {
                // 检查缓存
                if (_processCache.TryGetValue(process.Id, out var cached) &&
                    now - cached.LastCheck < _cacheExpiration)
                {
                    if (_videoPlayerProcesses.Contains(cached.ProcessName))
                    {
                        return true;
                    }
                    continue;
                }

                // 更新缓存
                _processCache[process.Id] = (process.ProcessName, now);

                if (_videoPlayerProcesses.Contains(process.ProcessName) &&
                    IsProcessWindowVisible(process))
                {
                    return true;
                }
            }
            catch { /* ignore */ }
        }
    }
    catch (Exception ex)
    {
        Debug.WriteLine($"MediaDetector error: {ex.Message}");
    }

    return false;
}
```

## 🔒 安全性和隐私问题

### 11. **窗口标题哈希缺少盐值**

**文件**: `SessionManager.cs:187-196`

```csharp
private string HashWindowTitle(string title)
{
    if (string.IsNullOrEmpty(title))
        return string.Empty;

    using var sha256 = System.Security.Cryptography.SHA256.Create();
    var bytes = System.Text.Encoding.UTF8.GetBytes(title); // ❌ 没有盐值
    var hash = sha256.ComputeHash(bytes);
    return Convert.ToBase64String(hash);
}
```

**问题**: 没有盐值,可能被彩虹表攻击

**建议**:
```csharp
private const string HashSalt = "RecordTime-V1-"; // 或使用配置文件中的随机盐值

private string HashWindowTitle(string title)
{
    if (string.IsNullOrEmpty(title))
        return string.Empty;

    using var sha256 = System.Security.Cryptography.SHA256.Create();
    var saltedTitle = HashSalt + title;
    var bytes = System.Text.Encoding.UTF8.GetBytes(saltedTitle);
    var hash = sha256.ComputeHash(bytes);
    return Convert.ToBase64String(hash);
}
```
